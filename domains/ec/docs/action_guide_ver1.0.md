# このガイドについて

本ガイドは、WEB ANALYTICS IMPROVEMENT GAME に登場する  
Action Card（施策カード）の学習用ガイドである。

本ゲームは、単に「正しい施策」を覚えることを目的としていない。

重要なのは、

- どの施策を選ぶべきか
- なぜその施策を選ぶのか
- どのようなリスクがあるのか
- クライアントや上司へどう説明するのか
- AIをどのように活用するのか

を考えながら、  
限られた条件の中で意思決定することである。

そのため本ガイドは、  
施策知識だけでなく、

- 提案力
- 説明力
- 判断力
- AI活用力
- 実務での注意点

を学ぶための  
「実践型Web改善ガイド」  
として設計している。

初心者は施策理解の補助教材として、  
実務者は提案・改善の振り返り資料として、  
それぞれ異なる視点で活用できる。

また、本ガイドは  
単なる施策解説ではなく、

- 「なぜその施策を選ぶのか」
- 「どのような順番で実施するのか」
- 「どのKPIへ影響するのか」
- 「AIをどう実務へ組み込むのか」

を考えるための  
“意思決定トレーニング教材”
として活用することを想定している。

そのため、各カードは  
「読む」だけではなく、

- 比較する
- 選択する
- 説明する
- 提案する
- 振り返る

ことを前提に設計されている。

---

# 各カードの構成

各カードは以下の8項目で統一して整理している。

1. この施策とは
2. 主な目的
3. 効果が出やすいケース
4. 活用例（具体施策＋AI活用）
5. クライアント説明のポイント
6. リスクと失敗例
7. ゲーム連携情報
8. 学習キーワード

なお、

- 「4. 活用例」は  
　「具体施策例」と「AI活用例」を左右比較形式で整理している。

- 「6. リスクと失敗例」は  
　「副作用」と「よくある失敗」を左右比較形式で整理している。

これは、

- 施策をどう実行するか
- AIをどう補助利用するか
- どのような失敗が起きやすいか

を比較しながら学べるようにするためである。
